수입축산물 이력관리시스템에서는 수입축산물(수입쇠고기, 수입돼지고기)의 이력관리에 필요한 응용서비스를 개발할 수 있도록 다양한 API를 제공합니다.

오픈서비스란?

서비스 운영자의 입장에서 데이터 플랫폼을 외부에 공개하여 다양한 응용 서비스 및 어플리케이션을 개발 할 수 있도록 외부 개발자와 사용자에게 API를 개방 하는 것을 말합니다.

API를 개방하게 되면 API 제공주체의 오픈서비스에서 사용되는 데이터를 활용할 수 있게 되어 유저(개발자) 들이 다양한 응용서비스를 개발 할 수 있습니다.

미트와치 오픈서비스

미트와치 오픈서비스는 E-marketplace, 포털사이트, 정부기관사이트, 개인블로그/홈페이지 등 수입축산물 유통 관련 사이트를 위한 조회오픈 서비스와 관련 업무 종사자의 생산, 유통, 판매 시스템을 위한 연계오픈서비스로 나뉩니다.

조회오픈서비스는 미트와치의 수입축산물 이력정보를 조회하기 위한 서비스이며 구현방식에 따라 Java API, Web Service, Jsp-XML, Jsp-HTML, REST 등이 있습니다.

연계오픈서비스는 미트와치에 수입축산물의 거래내역 및 제품생산내역을 입력하기 위한 서비스이며 구현방식에 따라 Java API, Web Service, REST 등이 있습니다.

오픈서비스 사용자 관리 정책

오픈서비스 이용 시 반드시 회원 가입 후 사용해야 합니다.

오픈 서비스 이용을 위한 자체 프로그램 개발, 프로그램 구매 등 사용하는 프로그램에 관계없이 서비스의 이용주체(아이디)는 미트와치에 등록되어야 함으로 회원 가입 후 이용해주시기 바랍니다.

오픈 서비스 이용 회원도 휴면계정 및 재동의 대상임을 알려드립니다.

미트와치 회원 정책(공지사항 게시글 16)을 확인하시고, 미트와치에서 오픈 서비스를 계속 이용하고자 할 경우 미트와치 사용자관리 정책을 준수하여 주시기 바라며, 탈퇴 회원이 될 경우 오픈 서비스를 이용하지 못하거나, 이용을 원할 경우 재가입해야 함을 알려드립니다.
